## What does this post show?

This draft shows one MDX component, `Callout`, and its Markdown fallback. The HTML page renders a styled box. The Markdown copy at `/blog/example-callout.md` renders a blockquote.

<Callout type="note">
  The Markdown copy of this box starts with **Note:**. Agents read it as plain text.
</Callout>

<Callout type="warning" title="Remember">
  Every new MDX component needs a Markdown fallback in the same slice. A unit test fails if one is missing.
</Callout>

## How do links behave?

Relative links, like the [about page](/about/), become absolute URLs in the Markdown copy.
